# Python Data Automation & Cleansing Pipeline

## Project Overview
This repository contains a **Python automation script** designed to simulate a real-world data engineering pipeline. It takes a raw, chaotic dictionary of customer profiles, performs rigorous data cleansing, computes operational/financial KPIs, and automates the export of structured reporting.

## Key Features & Skills Demonstrated:
*   **Data Cleansing:** Automated removal of leading/trailing whitespaces and string formatting standardization using `Pandas`.
*   **Deduplication:** Identification and elimination of redundant records to preserve data integrity.
*   **Financial Analytics:** Calculation of business metrics such as Total Portfolio Balance and Average Customer Balance.
*   **Operational Automation:** Instant pipeline pipeline processing with automated `.csv` file deployment.

## Technologies Used:
*   Python 3
*   Pandas Library

## How to Run:
1. Clone this repository.
2. Ensure you have pandas installed: `pip install pandas`
3. Run the script: `python data_cleaner.py`
